# Runtime

Use `pnpm infra:up`, then `pnpm --filter @ai-product-agent/database prisma:generate` and `pnpm --filter @ai-product-agent/database prisma migrate deploy` to start the local PostgreSQL/Redis runtime. Start `pnpm dev:api`, `pnpm dev:web`, and `pnpm dev:worker` in separate shells, then run `pnpm test:integration` with `DATABASE_URL` and `REDIS_URL` set. Stop with `pnpm infra:down`. `GET /api/health/live` checks process liveness; `GET /api/health/readiness` checks mode-appropriate PostgreSQL, Redis, storage, AI, and Shopify configuration. Production rejects missing PostgreSQL, Redis, OpenAI, encryption, or object-storage configuration.
